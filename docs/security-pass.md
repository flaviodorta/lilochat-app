## Known/accepted items (v1)

- **Playback accepts queue adds for unknown roomIds** (no cross-service FK —
  deliberate database-per-service consequence). Impact: orphan queue rows,
  invisible to users, now bounded by the 5/min bucket. Cleanup: the room
  archival sweep is the natural home (Phase 7 backlog).
- **`'unsafe-inline'` in script-src** — Next App Router hydration; strict
  nonce CSP requires per-request middleware, tracked as post-launch hardening.
- **Legacy YouTube API key** (old repo, pre-rewrite) must be deleted in Google
  Cloud Console — owner action, flagged in the rotation runbook.
